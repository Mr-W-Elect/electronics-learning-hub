# Electronics Learning Hub — Starter Edition

## Preview
Open `index.html` in a modern web browser. No installation or build tools are required.

## What's included
- Responsive student dashboard and navigation
- Learning resource topic cards
- Resistor color-code practice game
- Component identification quick-match activity
- Ohm's Law calculator and power calculator
- Five-question electronics fundamentals quiz
- Video topic links (YouTube search links for teacher review)
- Project and lab idea cards
- Quick-reference formulas and external learning tools

## Customize
Open `index.html` in a code editor (for example, Visual Studio Code).
- Change the site title and branding in the `<title>` and sidebar brand.
- Add lesson links to the Learning Resources page.
- Replace YouTube search links with teacher-reviewed videos.
- Add your own project instructions, worksheets, and reference files.
- Edit the quiz questions in the `quiz` array near the bottom of the file.

## Publish
This is a static website. It can be hosted on a static web host such as GitHub Pages, Netlify, or your school's approved web hosting service. Check district policy before publishing student-facing content or using third-party hosting.

## Important
This is a starter prototype, not a learning management system. It does not collect grades, save student progress, authenticate users, or provide teacher administration. Review all external links, videos, project instructions, and safety guidance before student use. Add approved lab procedures, risk assessments, and component ratings to hands-on activities.

# Electronics Learning Hub 

## What's included
- Responsive student dashboard and navigation
- Learning resource topic cards
- Resistor color-code practice game
- Component identification quick-match activity
- Ohm's Law calculator and power calculator
- Five-question electronics fundamentals quiz
- Video topic links 
- Project and lab idea cards
- Quick-reference formulas and external learning tools

## Publish
This is a static website. It can be hosted on a static web host such as GitHub Pages, Netlify, or school's approved web hosting service. Check district policy before publishing student-facing content or using third-party hosting.
